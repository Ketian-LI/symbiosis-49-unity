## Final-source scope

The final snapshot includes the approved Fill interface, restored town-paper motif, card-art goal rows,
selective guidance emphasis, real remaining-card catalogue, persistent room relationships and three settlement highlight batches.
Recurring bad-pair deductions, clickable manual terms, additional commuting diagrams, Enter-to-confirm and a separate P journal
are outside this pinned snapshot.

Saved interface verification records [38 selected EditMode checks](../Misc/evidence/automated-tests/approved-fill-ui-editmode.xml)
and [27 selected PlayMode checks](../Misc/evidence/automated-tests/approved-fill-ui-playmode.xml).
The repository reorganisation preserves that game source; it does not rebuild the executable or rerun those tests.
