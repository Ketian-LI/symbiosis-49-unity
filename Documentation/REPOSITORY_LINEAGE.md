# One process, distinct implementations

The repositories are connected by a design enquiry, not by a claim that every feature was ported unchanged.
Remote heads were checked on 20 November 2026; [the pinned metadata](history/related-repositories.json) preserves the results.

| Stage | Repository and inspected records | What this evidence supports |
| --- | --- | --- |
| Early browser exploration | [urban-wildlife-simulation](https://github.com/Ketian-LI/urban-wildlife-simulation), README, timeline, AI log and local Git history | Feeding, animal response and delayed effects were explored in a web implementation; these are not Unity runtime tests |
| Tangible/city experiment | [urban-wildlife-tangible-unity](https://github.com/Ketian-LI/urban-wildlife-tangible-unity), README and `docs/GDD_V3_MIGRATION.md` | A token/scan-preview-confirm and city-network direction was documented. Reported implementation labels are not new hardware validation by this archive |
| Room simulation and Research configurations | [symbiosis-49-unity main](https://github.com/Ketian-LI/symbiosis-49-unity/tree/main), source and historical README | The earlier 49-room systems, animal models and Research infrastructure form a distinct stage |
| Progressive construction | [historical construction commit](https://github.com/Ketian-LI/symbiosis-49-unity/commit/d5a8cc7ec03f95993370fe5626156aa61f959690) and [59-commit CSV](history/symbiosis-unity-history.csv) | The committed move towards sequential construction through 20 October 2026 |
| Current construction archive | [this branch](https://github.com/Ketian-LI/symbiosis-49-unity/tree/archive/2026-11-20), working-tree source and November test/capture records | V13 scoring, finite cards, goal-state repair, upgrades, result review and the neighbourhood journal |

The current source includes local changes made after the last construction commit. They are archived as a **new snapshot**;
the archive does not backdate commits or invent a day-by-day Git history for those changes. Git author dates are preserved
as recorded; the local web CSV contains 63 commits and is not a claim that all were gameplay changes.

The account's [wristband](https://github.com/Ketian-LI/wristband) and [ble-viewer](https://github.com/Ketian-LI/ble-viewer)
repositories were also checked. Their READMEs currently contain only the project names. They are listed as adjacent work,
not asserted to be part of this artefact's technical lineage without further author evidence.

Earlier repository histories remain in their original locations. Source is not copied from unrelated external projects,
and no old repository is frozen, deleted or renamed as part of this archive.
