# AI use and authorship

I developed the project's concept, research focus, game rules and visual direction, and made the creative decisions.
I selected references, specified changes and decided which revisions to keep. AI tools supported the implementation
and revision of my designs, as described below.

| Area | Assistance used |
| --- | --- |
| Code | ChatGPT/Codex provided programming and implementation support for Unity and browser code, tests, build scripts and debugging, following my design requirements. |
| Visual assets | AI image tools assisted with the production and revision of card illustrations and interface backgrounds, following my references and art direction. |
| Writing and translation | ChatGPT/Codex supported drafting, organisation and revision of project documents. DeepL supported translation. |
| Research material | ChatGPT/Codex helped organise and analyse some questionnaires, message extracts and transcripts. The data-handling implications are addressed in the [ethics reflection](ETHICS_REFLECTION.md). |

The [asset record](ASSET_PROVENANCE.md) identifies AI-assisted visual assets, third-party material and editable source files.
The [supporting record](../Misc/process/AI_USE_RECORD.md) links the available development logs and tool references.
Those records cover documented stages of the project; they are not a complete prompt-by-prompt history.
