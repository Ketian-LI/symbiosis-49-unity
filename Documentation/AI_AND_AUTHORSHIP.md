# AI use and authorship

I set the research direction, defined the game's requirements, selected visual references and decided which revisions to keep.
AI tools were used in code development, image production and writing, as set out below.

| Area | Use in this project |
| --- | --- |
| Code | ChatGPT/Codex generated and revised Unity and browser code, test code, build scripts and bug fixes. |
| Images | Image-generation tools produced concepts, card illustrations and interface backgrounds. I selected references and directed revisions to the visual style and layout. |
| Writing and translation | ChatGPT/Codex helped draft, structure and edit project documents. DeepL was also used in translation work. |
| Research material | ChatGPT/Codex was used to organise and analyse some questionnaires, message extracts and transcripts. The data-handling implications are addressed in the [ethics reflection](ETHICS_REFLECTION.md). |

Generated material, third-party assets and editable source files are identified in the [asset record](ASSET_PROVENANCE.md).
The [supporting record](../Misc/process/AI_USE_RECORD.md) links the available development logs and tool references.
Those records cover documented stages of the project; they are not a complete prompt-by-prompt history.
