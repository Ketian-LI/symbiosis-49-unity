# User testing evidence

The [method record](METHOD.md) describes two rounds of remote playtesting: 5 participants in the first and 13 in the second,
including the original 5. The study involved 13 different people.

The [evaluation](../../EVALUATION.md) connects the reported problems to design changes and states the limits of the evidence.
Detailed responses, signed forms, messages, audio and participant identities are not included in the public archive.
Formal review and the scope for further use of earlier feedback remain unresolved; see the
[ethics reflection](../../ETHICS_REFLECTION.md).
