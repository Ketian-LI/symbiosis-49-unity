# Assessment guide

The assessment combines project outcomes, an iterative research record, a project report and an associated thesis
of at least 3,500 words as PDF. The submission format is a GitHub-link text file and a ZIP containing the full repository.

| Material | Location |
| --- | --- |
| Required work and learning outcomes | [Requirements map](REQUIREMENTS.md) |
| Included material | [Submission inventory](SUBMISSION_CHECKLIST.md) |
| Source and download versions | [Delivery record](../PROJECT_STATUS.md) |
| Dissertation | [Thesis record](../../Thesis/README.md) |
| Ethics position | [Ethics reflection](../ETHICS_REFLECTION.md) |

The standard deadline in the supplied brief is 23 November 2026 at 14:00 GMT.
The adjusted deadline applies only where eligibility and use have been confirmed.
