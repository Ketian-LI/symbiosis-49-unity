# 狐狸 v03 点位与坐标约定

本版根据 2026-09-29 提供的狐狸正面、侧面、顶面参考图作近似重建。参考图不是带真实尺寸的工程图，因此这些数值是用于保持三视图轮廓一致的**建模控制点**，不是解剖测量数据。

## 坐标系

- 原点 `P00 = (0, 0, 0)`：四足之间的地面投影中心。
- `+X`：从尾部指向鼻尖，也就是狐狸前进方向。
- `+Y`：狐狸自身的左侧。
- `+Z`：向上。
- 左右肢体以 `Y = 0` 镜像，避免手工放置造成不对称。
- 脚底落在 `Z ≈ 0`，便于 Unity NavMesh 与地面贴合；模型整体缩放应放在动画节点外层。

## 文件和使用方式

- `Fox_狐狸_v03_点位建立.blend`：可编辑模型、骨架、动画和 `FOX_LANDMARKS_v03` 点位集合。
- `Fox_狐狸_v03_点位.csv`：完整控制点表，UTF-8 with BOM，Excel 可直接打开。
- `build_fox_from_landmarks_v03.py`：可重复生成模型和三视图预览。
- 当前 v03 是独立建模版本，没有覆盖 Unity 正在使用的 `Fox_Animated_v01.fbx`。确认造型之后再导出/替换游戏资产，可避免未经确认的模型直接进入最终研究版本。
