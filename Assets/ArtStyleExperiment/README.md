# SYMBIOSIS: 49 城市插画视觉试验

实际 Unity 项目中的独立场景：`Assets/ArtStyleExperiment/Scenes/UrbanArtStyleTrial.unity`。

## 打开

1. 在 `C:\Users\23902\Desktop\SYMBIOSIS-49-Unity-gameplay` 项目中选择菜单 `SYMBIOSIS 49 > Play Urban Art Style Trial`。当前工程设有主菜单作为 Play 的默认起始场景，因此请使用这个试验专用入口。
2. 切到 Game 视图。空格暂停或继续动作；`R` 从动作循环开头重新播放。停止播放后，默认起始场景会恢复。

## 试验内容

- 5×5 棋盘中展示十种地块。中列三格街道连通；地块贴图各占一格。
- 住宅、工作坊、餐厅、超市以城市街面立面呈现。
- 居民、车、鸽子、松鼠、刺猬、狐狸使用独立的透明图层；脚本切换动作姿态并移动居民、车与松鼠。
- 素材来源是已审核方向的概念图。此场景不调用原有放置、得分或动物行为系统，也不加入游戏启动流程。

## 验证边界

已在当前 `SYMBIOSIS-49-Unity-gameplay` 编辑器中打开场景，并通过试验专用菜单进入 Play。十种图块能完整按格显示，三格街道连续；居民、车辆与动物的姿态／位置随运行时间变化。控制台当次为 0 条错误、0 条警告。图集的 NPOT 缩放已关闭，以避免裁切错位。

这里的角色动作是概念图帧切换，不是最终逐帧动画或骨骼动画。地块是 2D 插画图集切片，不是 3D 房间模型。
