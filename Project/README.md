# Project versions

**Start with [04-Final](04-Final/README.md).** It is the final Unity source snapshot in this submission archive.
The other folders show the development stages and their separate source downloads.

| Version | Stage | Date | Role |

The final source is available directly in `04-Final/`. Earlier Unity stages are uploaded as individual source ZIPs,
with pinned commits and downloads in their version folders. This keeps the main repository focused on one directly openable
final project while preserving the earlier implementations.

Dates identify source snapshots.
[Downloads](Downloads/README.md) separates source packages from the earlier Windows executable.
The [development journal](../Documentation/DEVELOPMENT_JOURNAL.md) explains the transitions.
The [project report](../Documentation/PROJECT_REPORT.md) connects the artefact to the research question.
